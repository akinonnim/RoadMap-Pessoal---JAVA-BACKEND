# Introdução à Linguagem java

## Sobre a Linguagem Java

Java é uma das linguagens de programação mais aclamadas do mercado. Esse é um dos motivos pelos quais escolhi me profissionalizar nela. Além da empregabilidade, o ecossistema robusto permite a criação de sistemas extremamente organizados e complexos, mas fáceis de se manter. 

## Algumas caracaterísticas do Java

1. É uma linguagem **multi-paradigma**, ou seja, permite que você use "tipos" de lógica alinhados com a forma a qual vai codar. 
2. É uma linguagem **compilada**, significa que passa por um processo de "tradução" para que seja entendida em mais de um sistema, ou plataforma, sem que você precise necessáriamente alterar o código. É uma mega vantagem.
3. É muito popular em sistemas antigos (legado), bancos, e grandes empresas. 

## Sintaxe

A sintaxe é a forma como os comandos são ditos ao sistema. O java é conhecido por ser nativamente verboso - o que já não é mais verdade - e por isso, assusta, mas na prática, é bem simples. 

```java
public class ClasseExemplo{
    public static void main(String[] args){
    }
}
```
> Importante salientar: Toda linguagem tem uma sintaxe, e entre elas, existem similaridades e diferenças.

O que cabe de entender da sintaxe do Java por agora:

- *public* - significa que o elemento é de escopo público, logo pode interagir com qualquer outro elemento dentro do projeto, de alguma forma. 
- *class* - significa que é uma **classe**, classes são "moldes" para outros elementos, como objetos. 
- *static* - significa que é um método, estático no caso
- *void* - é um retorno, no caso vazio, referente ao próximo item, onde nosso código vai ser alocado
- *main* - é o método/ponto inicial do nosso código Java, é obrigatório

Parece confuso, e realmente é! Mas vamos por partes.
